## ShyFlow 3.9.8

Обновления теперь приходят из нового репозитория. Если у тебя 3.9.7 или старше, один раз скачай установщик отсюда вручную: дальше ShyFlow будет обновляться сам.

- Обновления проверяются цифровой подписью.
- Безопаснее работа с проектами в редакторах кода: ShyFlow не запускает git, если настройки репозитория могут выполнить чужую команду.
- Превью ссылок теперь выключено по умолчанию. Включить можно в настройках.
- Страница со скопированной ссылки больше не может подвесить остров.
- Копия базы уведомлений удаляется сразу после чтения.

**EN:** Updates now come from a new repository. If you have 3.9.7 or older, download this installer manually once; after that ShyFlow updates itself. Updates are verified with a digital signature. Safer git handling in code editor projects. Link previews are now off by default. A copied link's page can no longer freeze the island. The temporary copy of the notification database is deleted right after reading.
